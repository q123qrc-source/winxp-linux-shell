# Screenshots

Images shown in the top-level README. Meadow is **pre-alpha**. Every image was
captured in a container: headless labwc, Qt's software renderer, no GPU.

- `desktop.png`: a real Meadow session started from an `install.sh` install
  under `/usr/local` (phase 10).
- Everything else is a copy of a golden image from `tests/golden/`, made by
  `tools/screenshot-test.py` and the session screenshot scripts. These are
  copies, so re-baselining a test does not change the README; refresh them by
  hand when the UI changes.

The artwork (wallpaper, icons, logo, cursors) is original Meadow artwork
under CC-BY-SA-4.0. No Microsoft assets are used.
