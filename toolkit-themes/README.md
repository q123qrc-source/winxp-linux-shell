# Toolkit, icon, cursor and sound themes

Everything here is original and generated from code; nothing is drawn by
hand or taken from another theme.

| Directory | Generated by | When | Kept in sync by |
|---|---|---|---|
| `gtk.css.in`, `kvantum/MeadowLuna.kvconfig.in` | templates for `tools/gen-toolkit-themes.py` | build time: one GTK 3/4 theme and one Kvantum theme per `theme/*/theme.json` | ctest `toolkit_themes` |
| `icons/meadow-icons/` | `tools/gen-icons.py` | committed | ctest `icons_sync`, `icons_render` |
| `cursors/src/` | `tools/gen-cursors.py` (SVG + `cursors.txt`) | committed; `tools/gen-cursors.sh` builds the XCursor files | ctest `cursors_sync`, `cursors_build` |
| `sounds/meadow/` | `tools/gen-sounds.py` (needs `oggenc` to write) | committed; `pcm.sha256` holds the PCM hashes | ctest `sounds_sync` |

To change something, edit the tokens (`theme/<scheme>/theme.json`), a
template or a generator, then regenerate the committed parts:

```sh
tools/gen-icons.py        # toolkit-themes/icons/meadow-icons
tools/gen-cursors.py      # toolkit-themes/cursors/src
tools/gen-sounds.py       # toolkit-themes/sounds/meadow (oggenc from vorbis-tools)
tools/gen-toolkit-themes.py --lint
```

Review sheets: `tools/theme-sheet.sh --grab out.png --kind icons-48|icons-16|cursors`;
applications: `tools/toolkit-screenshot.sh --grab out.png --app gtk3|gtk4|qt [--scheme luna-olive] [--menu]`.
`tools/gen-sounds.py --wav DIR` writes the sounds uncompressed for listening.
